# 생정융: 좀비 바이러스로부터 탈출하라

충남대학교 생명시스템과학대학을 배경으로 한 웹 방탈출 게임입니다.

## 실행

별도 빌드 과정이나 외부 라이브러리가 필요하지 않습니다. BGM도 외부 음원 파일을 사용하지 않고 Web Audio API로 브라우저에서 직접 생성합니다.

`exploration.js`는 `game.js`보다 먼저 로드합니다. 학생회장의 시약보관실 기록은 음성 재생 없이 읽는 편지입니다. 기존 저장과 인계 내역의 호환성을 위해 내부 아이템 ID `president-voice`는 유지하지만, 화면·인벤토리·접수 목록에는 편지로 표시됩니다. BGM과 효과음은 유지됩니다. 이야기 속 인물·기업·사건은 허구입니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속합니다. 진행 상황은 브라우저에 자동 저장됩니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 `Deploy from a branch`와 `main / root`를 선택하면 배포할 수 있습니다.
