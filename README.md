# 생정융: 좀비 바이러스로부터 탈출하라

충남대학교 생명시스템과학대학을 배경으로 한 웹 방탈출 게임입니다.

## 현재 구현된 범위

1. 기업 탐방에서 돌아온 생정융 학생들의 프롤로그
2. 생명시스템과학대학 로비 탐색
3. 대학원생이 남긴 편지와 `101` 암호
4. 101호와 105호 선택
5. 105호 선택 시 좀비 추격 이벤트
6. 101호 선택 시 첫 챕터 완료
7. 미니맵을 이용한 좀비 거리 확인
8. 3회 물림과 제한 시간 게임 오버 시스템

## 실행

별도 빌드 과정이나 외부 라이브러리가 필요하지 않습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속합니다. 진행 상황은 브라우저에 자동 저장됩니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 `Deploy from a branch`와 `main / root`를 선택하면 배포할 수 있습니다.
