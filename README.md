# 생정융: 좀비 바이러스로부터 탈출하라

충남대학교 생명시스템과학대학을 배경으로 한 웹 방탈출 게임입니다.

## 현재 구현된 범위

1. 기업 탐방에서 돌아온 생정융 학생들의 프롤로그
2. 생명시스템과학대학 로비 탐색
3. 대학원생이 남긴 편지와 `101` 암호
4. 101호와 105호 선택
5. 105호 선택 시 좀비 추격 및 1회 물림 이벤트
6. 101호 컴퓨터실의 터미널 탐색 퍼즐
7. 로비를 거쳐 2층 자료열람실로 이동
8. 자료열람실 내부의 B-17 책장 조사
9. 미니맵을 이용한 좀비 거리 확인
10. 3회 물림과 제한 시간 게임 오버 시스템
11. 브라우저에서 실시간 생성되는 오리지널 공포 앰비언트 BGM과 음소거 기능
12. 접이식 인벤토리와 모바일 전용 HUD·하단 팝업 UI
13. B-17 책장의 형광등 탐색, 숫자 규칙 문제와 바리케이드 획득
14. 바리케이드 획득 후 진입 가능한 동물실험 연구센터와 감염된 실험쥐 조사
15. 접안·대물렌즈 배율 계산과 조동·미동 나사를 사용하는 현미경 관찰 퍼즐 및 서랍 개방
16. 서랍 속 문자 재조합 문제와 1층 좀비 급증·15초 제한 로비 바리케이드 설치 이벤트
17. 외부 검체 반입 기록, 감염된 실험쥐, 연동된 격리문과 같은 필체의 연구일지로 이어지는 스토리 단서
18. 형광등으로 드러나는 연구일지의 DNA 상보적 염기쌍 퍼즐과 과사무실 코드
19. 1420 출입 코드로 들어가는 생정융 과사무실과 조사 가능한 CCTV 콘솔
20. 과사무실 침입 경보 및 감염 조교 선택에 따른 추가 물림 이벤트
21. CCTV·기업탐방 명단·관리자 계정을 대조해 샘플 반입과 격리 해제의 범인이 생정융 학생회장임을 밝히는 스토리
22. Query cover·Identity·E-value를 비교해 3층 보관함 C-07을 찾는 BLAST 영상 복구 퍼즐
23. 냉각 상자와 학생회 완장이 찍힌 중단발 여성 학생회장의 CCTV 실루엣 및 식별 증거 화면
24. 성냥개비를 직접 끌고 90도 회전해 푸는 C-07 잠금 퍼즐과 2회 오답 시 좀비 물림 이벤트
25. 3층 저온 시료 보관실과 C-07 보관함 조사, 복구된 메신저 대화로 드러나는 기업의 채용 제안 및 학생회장의 격리 해제·기록 삭제 동기
26. C-07 증거 사진에서 직접 수집해 인벤토리에 보관하는 손상된 염기서열 칩
27. 3층 생물정보 분석실에서 상보적 염기쌍으로 DNA를 복원하고 mRNA 코돈을 번역해 ZV-SPIKE 표적 단백질을 찾는 2단계 퍼즐
28. 표적 분석 뒤 분자생물학실·세포배양실·시약보관실이 열리며, 프라이머 방향성·세포 배양 품질·항체 표적과 냉장 상태를 판별해 백신 재료 3종을 수집
29. 재료 퍼즐마다 첫 오답에 좀비 접근, 두 번째 오답에 1회 물림. 오답 횟수와 진행 상태는 저장되며 물림 연출 뒤 같은 퍼즐에서 재도전
30. 피나 상처 없이 팔의 붉은 자국으로 표시하는 물림 연출. 세 번째 물림은 게임 오버로 연결
31. 장소별 음색·음정 변화, 7초 간격 변주와 위험도에 따른 맥박 변화가 있는 합성 BGM
32. 풀이 힌트와 정답 염기 표시 제거, 후반 로비·미니맵의 장소 겹침 방지, 매초 버튼 재생성 방지 및 필수 이벤트의 Esc 처리
33. 프라이머 튜브를 끌거나 눌러 PCR 슬롯에 배치하는 작업대. 배양 접시는 확대 관찰, 항체는 집어 들고 앞·뒷면 라벨 조사 후 별도 버튼으로 획득 확정
34. 세 재료실에서 선택적으로 수집하는 학생회장의 사고 후 메모·비상 출입 기록·미전송 메시지. 발견 순서에 관계없이 증거 인벤토리에서 다시 확인 가능
35. 후반 로비의 층별 안내판, 이동·조사·위험 색상 구분 및 조사 완료 지점의 낮은 강조
36. 도구·증거·재료 인벤토리 분류와 일시적인 NEW 표시
37. 첫 재료 오답의 유리문 너머 그림자·발소리, 두 번째 오답의 짧은 암전 뒤 비유혈 물림 연출

38. 재료 3종 확보 후 보고서와 로비 층별 안내판에서 열리는 3층 통합 백신 개발실
39. 재료를 기능별 모듈에 배치한 뒤, 보유 보고서와 네 후보의 가상 실험 결과를 대조하는 2단계 검증 퍼즐
40. 검증 성공 시 백신 후보·검증 기록 수집, 내부 통신망에서 3층 비상 격리실의 생존자 신호 발견 및 수신 기록 보관

41. 생존자 신호 확보 뒤 로비 안내판에서 이동하는 3층 비상 격리실 관찰 구역과 유리문 너머 중단발 여성 학생회장
42. 검체 반입·격리 해제·외부 통신 차단·수습 협조에 관한 네 질문의 인터폰 대화. 읽은 대화와 마지막 질문을 저장하며 재열람 가능
43. 네 대화를 확인한 후 전달함에서 직접 수집하는 비상 전원 기록. 증거 인벤토리에 보관되며 차단 명령 서명과 로비 배전반의 제한 전력 정보 포함

44. 전원 기록을 가지고 로비로 돌아오면 시작하는 마지막 방어 장면, 바리케이드 흔들림과 비상 배전반
45. 8칸의 전력을 배분하는 2단계 퍼즐: 냉장을 유지하며 송신 구역 격리문을 구동하고, 기계식 고정 뒤 모터 전력을 송신기로 전환
46. 독립 비상 회선에서 구조대와 가상 교신, 검증 기록·생존자 위치 첨부 후 요청 전송, 수신 확인서 수집
47. 수신 확인서의 다음 교신으로 시작하는 구조 경로 확보: 과사무실 CCTV 세 곳의 중계 영상·관찰 기록과 1층 가상 도면 대조
48. 외부 출입구부터 로비까지 연결된 지점을 누르는 경로 퍼즐. 되돌리기·초기화 지원, 고정 장애물·감염체 구역을 피하는 경로 검증
49. 경로 승인 뒤 친구들과 운반 카트를 치우고 남측 보조문 잠금을 해제하는 협동 장면, 구조대 로비 합류와 진입 기록 수집
50. 구조대 합류 뒤 로비에서 후보·검증 기록·표적 보고서·C-07 기록·비상 전원 기록을 직접 선택하고 인계하는 접수 화면
51. 편지·연구일지·칩·학생회장의 추가 메모 등 보유한 선택 증거를 별도로 인계. 인계 후 인벤토리는 보관 사본·후보 접수 기록으로 유지
52. 의료진 상태 확인 보고와 보호 이송을 거쳐 학생회장이 로비 보호 구역에 합류. 네 장면의 직접 진술을 확인하고 인계 확인서·진술 사본 수집
53. 인계 완료 후 동행 학생 확인과 구조대의 안내를 거쳐, 확보한 경로의 역순으로 남측 보조문을 나서는 최종 대피
54. 새로운 건물 밖 구조 구역 배경과 탈출 성공 장면. 추가 검증·백신 배포, 사건 기록과 책임, 학생들의 이후를 다루는 세 편의 에필로그
55. 위험 구간 플레이 시간·물린 횟수·보관 기록·인계 항목을 보여 주는 결과 화면. 엔딩 중간 저장, 결과 및 에필로그 재열람, 확인 후 새 게임 시작

메인 스토리는 프롤로그부터 최종 탈출·에필로그까지 구현되어 있습니다. 전력 퍼즐의 문은 로비 안테나 구역의 격리문, 구조대 진입과 학생들의 대피에 쓰는 문은 1층 남측 보조문입니다. 3층 생존자 격리실은 구조팀과 의료진이 별도로 상태를 확인한 뒤 보호 이송하며, 다른 격리 구역을 일괄 해제하지 않습니다. 회장의 협조가 면책이나 감염 여부 확정으로 처리되지 않습니다. 백신 배포는 충분한 시간이 흐른 뒤 추가 검증과 생산을 거친 허구의 후일담입니다.

마지막 단계는 인계 확인서의 ‘구조대의 대피 안내를 확인한다’ 또는 로비의 ‘구조대 · 마지막 대피’에서 시작합니다. 대피 중간·건물 밖 도착·에필로그 페이지를 저장하며, 구버전 인계 완료 저장에서도 이어집니다. 탈출 후에는 내부 재진입과 추가 수집을 막고 항목 요약·인계 문서·진술·검증 사본을 열람합니다. 결과 카드는 인벤토리에 한 번만 추가됩니다. 재시작은 현재 저장과 결과를 덮어쓴다는 별도 확인을 거칩니다.

결과의 플레이 시간은 기존 게임 시계 기준으로 일시정지와 구조대 합류 후 대화·대피·에필로그 시간을 제외합니다. 기록 수는 탈출 순간의 증거 분류 아이템(접수 확인서 포함)이며 결과 카드 자체는 제외합니다. 인계 수에는 실물 후보와 실제 넘긴 자료만 포함합니다. 결과는 탈출 시점에 고정되며 에필로그를 다시 읽어도 변하지 않습니다. 엔딩에서는 추격 BGM을 낮은 긴장의 오리지널 합성 앰비언트로 바꿉니다.

인계 단계는 새 암호나 오답 패널티가 없는 이야기 구간입니다. 구조대가 방어를 맡아 시간·추격 정지가 유지됩니다. 핵심 항목 5개는 직접 인계해야 하며, 미확보 항목은 생성하지 않고 원래 장소에서 수집하도록 안내합니다. 추가 기록은 없어도 진행할 수 있고, 완료 후에도 인계할 수 있습니다. 접수 내역·의료진 보고·이송·진술 페이지는 저장되며, 구버전 구조대 합류 저장에서도 이어집니다. 기존 검증 기록·격리실 호출·구조대 진입 기록을 다시 볼 때 인계 및 이송 이후 상황을 반영합니다. 인계는 게임 속 처리이며 실제 의료기관·수사기관으로 전달하지 않습니다.

배전 조정만으로는 오답 처리되지 않으며 명시적인 실행으로 판정합니다. 첫 오답은 접근, 두 번째는 1회 물림이고 첫 배전 성공은 재도전·재접속 시 유지됩니다. 전송은 게임 안에서만 처리되며 외부 통신이나 실제 구조기관 호출을 수행하지 않습니다. 수신 확인 뒤 시간·추격은 대기하며, 다음 교신을 직접 확인하면 다시 진행됩니다. 구조대가 로비에 합류하면 이번 구간의 시간·추격을 정지합니다.

구조 경로는 드래그 없이 클릭·터치·키보드로 연결합니다. CCTV 열람·경로 편집·미완성 제출은 오답으로 처리하지 않습니다. CCTV 세 곳을 확인한 완성 경로의 검증 요청만 판정하며 첫 오답은 접근, 두 번째는 비유혈 물림 1회입니다. 전체 3회 물림 규칙은 유지합니다. 선택 경로, CCTV 확인, 오답, 승인과 통로 정리 상태를 저장하며 구버전 수신 완료 저장에서도 이어집니다. CCTV 컷은 기존 게임 배경을 재사용하며 구역별 관찰 기록과 함께 제공합니다. 도면은 퍼즐을 위한 가상 배치로 실제 건물의 피난 안내도가 아닙니다.

개발실 퍼즐의 배치와 후보 선택을 합쳐 첫 오답은 접근, 두 번째 오답은 1회 물림으로 처리합니다. 재료 배치·결과 열람만으로는 오답이 발생하지 않으며 빈 제출도 물림 횟수를 늘리지 않습니다. 올바른 배치와 확보한 재료는 재도전 시 유지됩니다. 실험 수치는 게임 전용 가상 데이터이며 실제 제조·투여 지침이 아닙니다.

로드 순서는 `exploration.js` → `vaccine.js` → `isolation.js` → `rescue.js` → `route.js` → `handoff.js` → `ending.js` → `game.js`입니다. 회귀 검증은 macOS에서 `/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc tests/exploration-check.js`로 실행할 수 있습니다. 이는 모의 DOM을 이용한 로직 검사이며 브라우저 렌더링 검사는 아닙니다.

개발실 배경은 내장 ImageGen으로 제작했으며 [생성 기록](assets/vaccine-image-notes.md)에 최종 프롬프트와 경로를 남겼습니다.
격리실 배경도 내장 ImageGen으로 제작했으며 [격리실 생성 기록](assets/isolation-image-notes.md)에 경로와 프롬프트를 남겼습니다. 기존 CCTV의 중단발·검은 옷·붉은 완장을 참고해 인물의 연속성을 유지했습니다.
마지막 로비 배경은 기존 로비를 내장 ImageGen으로 편집한 별도 에셋입니다. [로비 생성 기록](assets/rescue-image-notes.md)에 경로와 프롬프트를 남겼습니다.
건물 밖 대피 장면은 내장 ImageGen으로 만든 가상 캠퍼스 이미지입니다. [엔딩 배경 생성 기록](assets/ending-image-notes.md)에 최종 파일과 프롬프트를 남겼습니다. 오후 기업 탐방 직후의 시간대에 맞춰 야간·새벽이 아닌 흐린 오후로 제작했습니다.

물림 연출 이미지 `assets/images/non-graphic-bite-mark.jpg`는 내장 ImageGen으로 제작했습니다. 최종 프롬프트는 어두운 연구실 복도를 배경으로, 팔의 온전한 피부 위에 분장 같은 붉은 반원 자국 두 개만 보여주는 비유혈성 장면입니다.

## 실행

별도 빌드 과정이나 외부 라이브러리가 필요하지 않습니다. BGM도 외부 음원 파일을 사용하지 않고 Web Audio API로 브라우저에서 직접 생성합니다.

`exploration.js`는 `game.js`보다 먼저 로드합니다. 미전송 메시지의 듣기 기능은 기기의 한국어 음성 합성을 사용하며 녹음된 성우 음원이 아닙니다. 미지원·음소거 환경에서는 대본으로 읽을 수 있고, 닫기·일시정지·음소거 시 재생을 중단합니다. 이야기 속 인물·기업·사건은 허구입니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속합니다. 진행 상황은 브라우저에 자동 저장됩니다.
